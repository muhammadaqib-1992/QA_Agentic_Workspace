## Keeping this current

The index is only trustworthy if it is written when the call happens. A useful habit: add the entry before the recording is filed. An index that lags reality is worse than none, because the agent will trust it anyway.

**Decisions recorded here often supersede the written specification** — teams rarely go back and update documents after changing their minds. When the index and a document disagree, that conflict is itself the finding; surface it rather than quietly picking a side.
